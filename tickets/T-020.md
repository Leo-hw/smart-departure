# T-020 — 제공자 중립 대중교통 경로 안내

**상태**: 🟢 DONE
**담당**: Codex
**의존**: T-018, T-019

## 목표

기존 Google Routes 조회에서 시간뿐 아니라 승하차·환승·도보 단계를 받아 준비/출발 알림에 표시한다. 향후 다른 경로 제공자로 바꾸더라도 알림 모델은 재사용한다.

## Acceptance Criteria

- [x] `RouteGuide`/`RouteSegment`는 제공자 이름과 API 응답 필드에 의존하지 않는 공통 모델이다.
- [x] 대중교통 요청은 각 알림 평가 시점의 현재 경로를 조회하고 필요한 단계 필드만 요청한다.
- [x] Google 응답의 도보 구간과 노선·승하차·정거장·탑승 시각을 공통 모델로 변환한다.
- [x] 준비/출발 알림에 조회 시점의 간단한 경로와 `Google Maps` 출처를 표시한다.
- [x] API 오류·단계 누락 시 기존 이동 시간 fallback과 알림 전송을 유지한다.
- [x] 경로 상세는 캐시와 일정 스냅샷에 저장하지 않는다. 기존 알림 dedup 키는 바꾸지 않는다.
- [x] 단위/회귀 테스트 및 문법 검사를 통과한다.

## 범위 밖

- 경로 변화만을 이유로 하는 추가 알림은 보내지 않는다. 기존에 설정한 준비 단계와 출발 알림에서만 최신 경로를 표시한다.
- 지도 앱 내 실시간 길안내는 대체하지 않는다.
- T-016 카카오 대중교통 전환은 별도 결정이다.
