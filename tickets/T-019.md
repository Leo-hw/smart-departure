# T-019 — 캘린더 일부 접근 실패 시 나머지 일정 처리

**상태**: 🟢 DONE
**담당**: Codex
**의존**: -

## 배경

`GOOGLE_CALENDAR_IDS` 중 한 캘린더가 404를 반환하면 전체 실행이 실패해 다른 캘린더의 알림도 중단된다. begonia에서 서비스 계정이 접근할 수 없는 다섯 번째 캘린더를 추가했을 때 재현됐고, 현재 해당 ID는 제거됐다.

## Acceptance Criteria

- [x] 캘린더별 403/404는 안전한 경고를 남기고 나머지 캘린더 조회를 계속한다.
- [x] 모든 캘린더가 실패한 경우 성공으로 보고하지 않는다.
- [x] 인증·할당량·네트워크 오류의 처리 기준을 명시하고 테스트한다.
- [x] 경고 로그에는 캘린더 ID, 일정명, 주소, 자격 증명, 원문 API 응답을 출력하지 않는다.
