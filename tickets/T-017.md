# T-017 — 이동 시간 변동 시 중복 알림 방지

**상태**: 🟢 DONE
**담당**: Codex
**의존**: T-015

## 배경

begonia 폰 운영 시험에서 같은 일정의 대중교통 이동 시간이 24→38→25분으로 바뀌자 준비·출발 알림이 반복 전송됐다. 기존 dedup 키에 계산된 `alert_time`이 포함되어 매 실행마다 다른 알림으로 취급됐다.

## Acceptance Criteria

- [x] 일정 ID·일정 시작 시각·알림 종류로 안정적인 dedup 키를 만든다.
- [x] 향후 다단계 준비 알림은 명시적인 단계 식별자로 분리할 수 있다.
- [x] 이동 시간만 바뀐 같은 일정의 준비·출발 알림은 각각 두 번째 평가에서 건너뛴다.
- [x] 일정 시작 시각 또는 단계가 바뀌면 별도 알림으로 취급한다.
- [x] `.runtime/sent_alerts.json`의 해시 저장 및 만료 동작을 유지한다.

## 운영 주의

기존 저장 파일에는 이전 키의 8자리 해시만 남아 있어 새 키로 역변환할 수 없다. 배포 직후 이미 전송된 일정은 1회 재전송될 수 있다. 운영 중 실제 재발송 여부는 폰 로그로 확인한다.
