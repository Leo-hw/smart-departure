# T-018 — 대중교통 이동 시간 변동 정책

**상태**: ⚪ READY
**담당**: Codex
**의존**: T-017

## 배경

begonia 시험에서 같은 경로의 Google Routes 대중교통 소요 시간이 5분 간격으로 24→38→25분 바뀌었다. 요청에 `departureTime`이 없어 다음 차 시간에 따라 달라졌을 가능성이 있으나 원인은 미확인이다. T-017은 재발송을 막지만 계산된 출발 시각의 변동은 남는다.

## 조사 및 Acceptance Criteria

- [ ] 같은 일정·경로에서 요청 시각, 반환 소요 시간, 계산된 출발 시각을 민감 정보 없이 비교한다.
- [ ] `departureTime` 지정, 최초 계산값 고정, 증가하는 쪽만 반영 중 실제 알림 목적에 맞는 정책을 선택한다.
- [ ] 선택한 정책에서 일정 수정·이동 시간 급증·캐시/추정값 전환 시 동작을 검증한다.
- [ ] 테스트와 운영 검증 결과를 리포트에 기록한다.
