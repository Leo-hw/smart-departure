# T-015 — Google 이동 시간: Directions API(Legacy) → Routes API

**상태**: 🟠 VERIFY
**담당**: and-to-server(인프라 팀, begonia 폰 이전 작업 중 예외로 수정)
**의존**: -
**배경 문서**: ai-dashboard `docs/handoff-and-to-server-smart-departure.md` 4-1절

---

## 배경

- 새로 발급한 `GOOGLE_MAPS_API_KEY`는 Routes API용이라, 기존 코드가 호출하던 Directions API(Legacy)
  `maps/api/directions/json`에서는 실패한다.
- 실패하면 이동 시간을 30분으로 추정해 알림에 "(이동 시간 추정)"이 붙는다.

## Acceptance Criteria

- [x] `_GoogleMapsProvider`가 `POST https://routes.googleapis.com/directions/v2:computeRoutes`를 호출
  (`X-Goog-Api-Key`, `X-Goog-FieldMask: routes.duration`, 키는 URL에 넣지 않음)
- [x] 이동 수단 매핑: transit→TRANSIT, walking→WALK, driving→DRIVE(실제로는 카카오가 처리), 그 밖→TRANSIT
- [x] 응답 `routes[0].duration`("2100s")을 분으로 변환. 빈 응답·형식 오류·HTTP 오류는 기존처럼 캐시 → 30분 추정
- [x] 공개 함수 `get_travel_time()`와 `TravelResult`, 캐시·카카오 경로는 그대로
- [x] 단위 테스트 갱신·추가(50개 통과)
- [ ] begonia 폰에서 실제 키로 손 실행 → 로그 `estimated=False` 확인
